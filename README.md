# DailyArtifacts

Плагин для Paper 1.21.4: каждый период (1ч–7д, задаётся случайно в config.yml) сервер
выбирает от 1 до 5 случайных ванильных предметов как «артефакты дня». Игроки сдают их
через GUI (`/ad menu`) и получают игровую валюту через Vault.

## Сборка через GitHub Actions (из Термукса)

```
cd storage/emulated/0/NoxenVisuals/AD
git init                      # если ещё не инициализирован
git add .
git commit -m "plugin"
git push
```

После пуша GitHub Actions (`.github/workflows/build.yml`) сам соберёт проект через Maven
и приложит готовый `DailyArtifacts-1.0.0.jar` во вкладке **Actions → (последний запуск) →
Artifacts** этого репозитория. Просто скачай оттуда jar и закинь на сервер в `plugins/`.

## Важно про экономику

Плагин работает через **Vault API**. Если на сервере стоит только CMI без самого
плагина **Vault** — деньги начисляться не будут (в консоли будет предупреждение при
старте). Нужно поставить оба плагина: `Vault.jar` + `CMI.jar` — CMI сам зарегистрируется
как провайдер экономики для Vault, ничего дополнительно настраивать не нужно.

## Команды и права

| Команда | Что делает | Право |
|---|---|---|
| `/ad menu` | Открыть меню сдачи артефактов | `dailyartifacts.menu` (по умолчанию: все) |
| `/ad settings` | Редактировать список возможных артефактов | `dailyartifacts.settings` (по умолчанию: OP) |
| `/ad reload` | Перезагрузить все конфиги без рестарта | `dailyartifacts.settings` |

Режим прав настраивается в `config.yml` → `permissions.permission_mode`:
`simple` (OP/не-OP), `pex` (PermissionsEx) или `lp` (LuckPerms).

## Файлы конфигурации (создаются в `plugins/DailyArtifacts/` при первом запуске)

- `config.yml` — период обновления, кол-во артефактов, формат времени, звуки, права
- `items.yml` — пул всех возможных предметов (материал/цена/лимит/enabled)
- `menu.yml` — оформление обоих GUI
- `messages.yml` — все тексты игрокам
- `data/state.yml` — текущая ротация (сохраняется между рестартами)
- `data/players.yml` — прогресс сдачи по каждому игроку

## PlaceholderAPI (опционально)

- `%dailyartifacts_time_left%` — время до обновления
- `%dailyartifacts_count%` — сколько артефактов активно
- `%dailyartifacts_progress_<id>%` — прогресс игрока по конкретному артефакту (id из items.yml)


## Обновлённое `/ad settings`

Теперь `/ad settings` открывает именно главное меню настроек, а не сразу список предметов:

1. **Настройка лута** — отдельное GUI со списком предметов.
2. **Обновление артефактов** — настройка `update-time.min` и `update-time.max` через чат.
3. **Количество артефактов** — настройка `artifact-count.min` и `artifact-count.max` через чат.

`enabled` у предметов намеренно остаётся только в `items.yml`.

## Исправление префикса

Сообщения теперь действительно проходят через `ColorUtil`, поэтому `&#RRGGBB`, обычные `&`-коды и MiniMessage не выводятся в чат как сырой текст.
